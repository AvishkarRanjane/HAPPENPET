# HAPPENPET Website

A simple static website for HAPPENPET with pages for home, about us, product listing, cart, and login.

## Project Structure

- `index.html` - Homepage
- `aboutus.html` - About Us page
- `aple.html` - Product listing or detail page
- `cart.html` - Shopping cart page
- `login.html` - Login page
- `main.js` - JavaScript for interactive website behavior
- `style.css`, `style1.css`, `style2.css`, `style3.css`, `style4.css` - Stylesheets used across the site

## Usage

1. Open `index.html` in a web browser.
2. Navigate through the pages using the site links.

## Notes

- This is a static website, so no server-side setup is required.
- If you want to preview the site locally with refresh support, use any static file server such as Live Server in VS Code.
